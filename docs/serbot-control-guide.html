AIoT SerBot / Jetson

SerBot 제어 라이브러리 사용설명서

이 문서는 이 프로젝트에서 만든 goal 명령어와 serbot_control Python 라이브러리로 로봇을 안전하게 제어하고, 초음파, 카메라, LiDAR 값을 가져오는 방법을 정리한 매뉴얼입니다.

현재 기본 대상 soda@threnody.local

현재 확인된 Wi-Fi IP는 192.168.0.68입니다.

안전 제한

주행 속도 예제와 기본값은 10 이하로 맞췄습니다.

빠른 시작 안전 규칙 명령어 목록 Python 사용법 센서 카메라 스트리밍 대시보드 문제 해결

1. 빠른 시작

로봇이 같은 네트워크에 있고 SSH가 살아 있으면 아래 순서로 확인합니다. 처음 연결한 로봇에는 런타임을 한 번 배포해야 합니다. 최신 CLI에서는 설정 확인, 자동 탐색, 진단 명령을 먼저 실행할 수 있습니다. 

./goal config
./goal discover
./goal status
./goal deploy-all
./goal doctor
./goal probe
정상 기준: status는 호스트명과 IP를 출력하고, doctor는 런타임/CAN/카메라/LiDAR 상태를 모터 주행 없이 확인하며, probe는 can_stop=ok와 초음파 배열을 출력합니다.

2. 안전 규칙

속도 제한

현재 문서와 기본값은 10 이하를 기준으로 하며, CLI/라이브러리가 기본 차단합니다.

짧게 테스트

처음 주행은 0.2~1.0초 정도로 짧게 보냅니다.

정지 우선

이상하면 바로 ./goal stop을 보냅니다.

주의: 예전에 속도 99는 위협적으로 빨랐습니다. 지금 문서에서는 사용하지 않습니다.

3. 자주 쓰는 명령어

목적 명령어 설명
설정 확인 ./goal config 비밀번호를 노출하지 않고 현재 SSH/안전 설정을 출력합니다.
로봇 탐색 ./goal discover 알려진 hostname/IP 후보의 SSH 포트를 확인합니다.
연결 확인 ./goal status SSH 접속, 호스트명, IP, 커널을 확인합니다.
전체 진단 ./goal doctor 모터를 움직이지 않고 런타임, CAN, 카메라, LiDAR 장치를 확인합니다.
런타임 배포 ./goal deploy-all 모터/초음파 런타임과 카메라 스트림 서버를 Jetson에 복사합니다.
안전 정지 ./goal stop CAN 정지 프레임을 반복 전송합니다.
초음파 확인 ./goal probe 정지 프레임 후 초음파 값을 읽습니다. 주행하지 않습니다.

방향 주행

./goal forward --speed 10 --seconds 1
./goal backward --speed 8 --seconds 1
./goal spin-left --speed 8 --seconds 0.5
./goal spin-right --speed 8 --seconds 0.5
./goal stop

정밀 제어

drive는 선속도/각속도 느낌으로 제어합니다. linear > 0은 전진, angular > 0은 좌회전 성향입니다. 

./goal drive --linear 8 --angular 0 --seconds 0.8
./goal drive --linear 10 --angular 3 --seconds 0.8
./goal drive --linear 0 --angular 8 --seconds 0.4 --guard-direction none

raw는 좌/우 휠을 직접 제어합니다. 이 로봇의 직진 부호는 left=양수, right=음수입니다. 

./goal raw --left 10 --right -8 --seconds 0.5
./goal raw --left 0 --right 0 --seconds 0.1

시퀀스 실행

여러 짧은 동작은 맥에서 SSH를 여러 번 보내지 말고, sequence로 Jetson 안에서 한 번에 실행합니다. 

./goal sequence --json '[
  {"linear": 8, "angular": 0, "seconds": 0.5},
  {"linear": 10, "angular": 3, "seconds": 0.7},
  {"left": 0, "right": 0, "seconds": 0.1, "guard_direction": "none"}
]'

4. Python 코드에서 쓰기

자유롭게 코딩할 때는 serbot_control 패키지를 사용합니다. 명령어와 같은 기능이 Python 함수로 열려 있습니다. 

from serbot_control import MotionStep, SerBot

robot = SerBot.from_env()

print(robot.status())
robot.forward(speed=10, seconds=1)
robot.stop()

robot.drive(linear=10, angular=2, seconds=0.6)
robot.wheels(left=10, right=-8, seconds=0.4)

robot.sequence([
    MotionStep.vector(8, 0, seconds=0.5),
    MotionStep.vector(10, 3, seconds=0.7),
    MotionStep.wheels(0, 0, seconds=0.1, guard_direction="none"),
])

센서까지 같이 쓰는 예시는 아래 파일에 있습니다.

python3 examples/precision_control.py

5. 센서 읽기

초음파

./goal ultra --count 3
./goal probe

raw_cm, front_min, rear_min을 봅니다.

LiDAR

./goal lidar --output artifacts/lidar/latest-scan.json

한 프레임의 /scan을 JSON으로 저장하고 요약을 출력합니다.

카메라 스냅샷

./goal camera --output artifacts/camera/latest.jpg

한 장의 JPEG를 저장합니다. 실시간 영상은 다음 섹션을 사용합니다.

6. 카메라 스트리밍

SSH로 프레임을 계속 가져오면 끊깁니다. 그래서 실시간 영상은 로봇에서 MJPEG 서버를 띄우고, 브라우저가 내부망으로 직접 접속합니다. 

./goal camera-stream start --port 8766 --width 640 --height 360 --fps 10 --quality 70
./goal camera-stream url
./goal camera-stream status
안정값: 640x360 / 10fps / quality 70은 실제로 약 8~9fps 정도 수신됐습니다.

30fps를 시도할 때는 낮은 해상도로 시작합니다.

./goal camera-stream start --port 8766 --width 424 --height 240 --fps 30 --quality 65

스트림 주소는 보통 아래 형식입니다.

http://threnody.local:8766/stream.mjpg

7. 웹 대시보드

브라우저에서 주행, 초음파, 맵, 카메라 스트림을 같이 볼 수 있습니다.

8. 문제 해결

증상 확인할 것 명령어
로봇 SSH가 안 됨 mDNS 이름과 IP를 다시 찾습니다. dns-sd -B _ssh._tcp local
goal이 다른 로봇을 봄 명령마다 target을 지정합니다. ./goal --target soda@threnody.local status
카메라 스트림이 안 뜸 서버 상태와 URL을 확인합니다. ./goal camera-stream status
LiDAR가 느리게 뜸 첫 스캔까지 시간이 걸릴 수 있습니다. ./goal lidar --output artifacts/lidar/latest-scan.json
